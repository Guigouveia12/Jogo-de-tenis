# 🎾 Tennis Game

Um mini-jogo arcade de tênis desenvolvido em Python com **Pygame**, onde o objetivo é rebater a bola usando o mouse como raquete e desafiar uma IA adversária em níveis crescentes de dificuldade. O jogo inclui um menu interativo, personalização de quadra e raquete, torcida animada e efeitos sonoros.

---

## 🚀 Como Jogar

1. **Execute o jogo** com:

   ```bash
   python main.py
   ```
2. No **menu inicial**, selecione:
   * O estilo da **quadra** (verde, azul ou laranja)
   * A **cor da raquete**
3. Use o **mouse** para mover sua raquete.
4. **Clique** na bola quando ela estiver na área de rebatida (parte inferior da tela).
5. Acumule pontos e combos, e desafie a **raquete adversária automática**!
6. Pressione `ESC` ou `R` para voltar ao menu.

## 📦 Instalação

1. Clone o repositório:

   ```bash
   git clone https://github.com/seu-usuario/tennis-game.git
   cd tennis-game
   ```
2. Instale as dependências:

   ```bash
   pip install pygame
   ```
3. Execute o jogo:

   ```bash
   python main.py
   ```

---

## 📌 Controles

* **Mouse:** Mover raquete
* **Clique esquerdo:** Rebater a bola
* **R / ESC:** Voltar ao menu após game over
